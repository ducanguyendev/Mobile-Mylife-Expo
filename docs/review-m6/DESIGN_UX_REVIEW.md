# Calendar design and accessibility

The month calendar uses existing ivory/sage surfaces, rounded day cells, Anniversary/Family accent rails and Monday-first weekdays. Date labels include full dates and event counts by type. Letter/count indicators distinguish event types alongside color. Today and selection use explicit labels/borders. The bounded month grid accompanies a virtualized chronological-list alternative with search, type/date filters and visible/total counts.

Calendar opens in the current Vietnam month. Previous/next month and draft month/year jump support1800–2200. Today selects the Vietnam business date. A visible coverage explanation describes the provided next-occurrence dates. Cards wrap complete titles and detail views show complete notes, original/upcoming dates, member links, place and host.

Native forms reuse safe areas, keyboard avoidance, scroll reachability, labeled fields, reduced-motion modal settings and existing button targets. Searchable member selection supports100+ candidates with draft/cancel semantics. Death-member eligibility and date matching are explained near the controls. Save/delete feedback, retries, unsaved-discard and title-specific confirmation have VI/EN copy.

Actual native viewport/theme/font/keyboard/Back results are recorded in NATIVE_SMOKE_RESULTS. Contrast14 verifies inherited semantic controls. Hardware screen-reader speech/focus, external keyboard traversal and native reduced-motion focus remain independent device gates until actually tested.
