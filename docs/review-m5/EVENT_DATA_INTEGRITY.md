# Event data integrity

Derived identities are source-qualified, validated and never sent to edit/delete endpoints. Read-only details retain source reference and explain profile-date ownership or future anniversary management. Localized birth/death titles are presentation only; custom/anniversary titles are not rewritten. No duplicate client derivation.

Event forms mount a private draft. Full exact date and year-only modes are explicit; approximate is independent and retained. Optional coordinates describe only an event, not member Map location. All editable write fields are populated/preserved, including hidden optional coordinates and legacy supported type. Member pickers virtualize/search the entire directory, and Cancel/Back discards only their private draft. Main form warns before unsaved discard. No request before explicit Save.

The account-local mutation controller serializes create/update/delete before network work. Fresh GET compares every write field and source identity before update/delete. A changed event warns; missing update warns; missing delete is already authoritatively removed and needs no DELETE. Each completed mutation refetches full authoritative Timeline; save must find the acknowledged ID with normalized expected fields, delete must be absent. A missing/conflicting post-save result is not success.

An uncertain dispatched mutation locks further mutations until explicit authoritative reconciliation, preventing blind duplicate POST/DELETE. Localized feedback distinguishes this state. Delete confirmation shows the exact event title and supports cancel/Back; derived and legacy birth/death never show active Edit/Delete. Native/API auth layer remains unchanged. Blur/background aborts request work and closes sensitive dialogs; keyed account/member components and query cancellation suppress old-account/late results. Lifecycle controller denies operations before focus or after blur.

Residual risk remains: fresh GET/compare/PUT or DELETE is not transactional; Backend has no conditional version/ETag contract. Another writer can race between the check and mutation. Post-save read catches some uncertainty, not every possible interleaving. Cancellation cannot undo an already-applied server mutation. RISK-03 and M5 edit/delete race remain open.

Real integration evidence covers Expo→Web read→Web update→Expo, leap date/year0099/year0001, primary+related member scope, negative derived delete rejection, original anniversary date, stale edit/delete, malformed inputs400, foreign IDs404, USER isolation, ADMIN403, anonymous401 and cookie CSRF-related403. Unrelated Timeline writes preserve member relations/avatar/location and derived rows. Inherited M3/M4 integration suites replay unchanged. Synthetic adapters do not validate real Drive/provider behavior.
